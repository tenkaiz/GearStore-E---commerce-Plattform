# Week 7 Worklog (15/06/2026 – 21/06/2026)

#### 1. Weekly Objectives
- Practice the Maven build and packaging process.
- Configure the Maven Shade Plugin to package all project dependencies.
- Generate an executable JAR file for AWS Lambda deployment.

#### 2. Technical Activities Summary
This week focused on the build and packaging process of Java applications using Apache Maven. I studied the Maven project lifecycle, including compile, test, package, and install phases. In addition, I configured the **maven-shade-plugin** to bundle all required dependencies into a single executable JAR file suitable for AWS Lambda deployment. Practical exercises included building the Spring Boot project, validating the generated JAR file, and ensuring all application dependencies were correctly packaged for serverless execution.
