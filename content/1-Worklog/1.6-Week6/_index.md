# Week 6 Worklog (08/06/2026 – 14/06/2026)

#### 1. Weekly Objectives
- Study AWS Serverless Java Container.
- Understand the Request/Response mapping mechanism between Spring Boot and AWS Lambda.
- Analyze the request processing workflow of Serverless applications.

#### 2. Technical Activities Summary
This week focused on integrating Spring Boot applications with AWS Lambda using the AWS Serverless Java Container library. I studied how HTTP requests from API Gateway are transformed into Servlet requests and processed by the Spring Boot framework. Additionally, I analyzed the Request/Response mapping mechanism, the initialization process of the application context, and the execution flow from AWS Lambda to Spring Boot controllers. Hands-on exercises were conducted to understand the architecture and lifecycle of Java-based Serverless applications.
